# Recorded-route navigation for ROS 2 Jazzy

This branch provides the unicycle MPPI controller and reference costmap generator
used by the Misachiya workspace. Build and launch them from the workspace with
`ros2 launch misachiya_bringup navigation.launch.py route_bag:=/path/to/rosbag`.

See the [recorded navigation instructions](https://github.com/taku0625/misachiya_ws/blob/codex/nullspace-mpc-ros2-jazzy/docs/recorded-navigation.md).
